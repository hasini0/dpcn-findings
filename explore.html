Explore it yourself

This site tells the story. The interactive dashboard has every number behind it, for each institute and each author-count view, plus an author explorer that draws anyone's co-author network.

The dashboard is one 14 MB page, so it takes a few seconds to load.

Good places to start

  • SINP without large collaborations: switch between All papers and < 10 authors to see the difference.
  • Faculty groups: each faculty member's students and co-authors.
  • Kolkata neighbours: ISI, Jadavpur, Calcutta University, IACS, IISER Kolkata and VECC.
  • Indian connectivity: every partner institute, with a search box.

The data

The raw OpenAlex download (about 150 MB zipped) is not in this site's repository. The submitted files are group23_data.csv (one row per paper × author × institute), citation_network.csv, authorship_network.csv and indian_connections.csv, built from OpenAlex by our pipeline. This site uses one small file derived from the dashboard's statistics, data/findings.js.
